## 1. Qisqacha ta'rif
Mean ($\mathbb{E}[x]$ yoki $\mu$) — tasodifiy o'zgaruvchining matematik kutilmasi (expected value) yoki ma'lumotlar to'plamining arifmetik o'rtacha qiymati (1st moment).

## 2. Nima uchun kerak?
[Batch Normalization](/learn/batch-normalization) (Ioffe & Szegedy, 2015): Har bir qatlam aktivatsiyasi mini-batch o'rtachasi $\mu_{\mathcal{B}}$ yordamida markazlashtiriladi:
$$
\mu_{\mathcal{B}} = \frac{2.0 + 4.0 + 6.0 + 8.0}{4} = \frac{20.0}{4} = 5.0
$$

Markazlashtirilgan qiymatlar ($\hat{x}_i = x_i - \mu_{\mathcal{B}}$): [-3.0, -1.0, 1.0, 3.0] (yangi o'rtacha qiymat 0.0 ga teng).

## 3. Python Amaliy Misoli: O'rtacha va Markazlashtirish

```python
import numpy as np

activations = np.array([2.0, 4.0, 6.0, 8.0], dtype=np.float32)
mu = activations.mean()
centered = activations - mu

print("Mini-batch o'rtachasi (mu):", float(mu))          # 5.0
print("Markazlashtirilgan vektor:", centered.tolist())      # [-3.0, -1.0, 1.0, 3.0]
print("Yangi o'rtacha:", round(float(centered.mean()), 6)) # 0.0
```
