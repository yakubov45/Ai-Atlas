## 1. Qisqacha ta'rif
Retrieval-Augmented Generation (RAG) — Patrick Lewis, Ethan Perez, Aleksandra Piktus, Fabio Petroni va hammualliflar (May 2020, "Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks", arXiv:2005.11401) tomonidan bilimga asoslangan (knowledge-intensive) NLP vazifalari uchun taklif etilgan, qidiruv (retrieval) va matn generatsiyasini (generation) birlashtiruvchi arxitektura.

## 2. Nima uchun kerak?
Standart [LLM](/learn/llm) va [Transformers](/learn/transformers) modellari bilimlarni faqat o'z parametrlarida saqlaydi. Bilimga asoslangan murakkab NLP vazifalarida modelga tashqi hujjatlar bazasidan tegishli ma'lumotlarni vektor yaqinligi ([Embeddings](/learn/embeddings), [Vector](/learn/vector)) orqali qidirib topish va javobni shu ma'lumotlar asosida generatsiya qilish talab etiladi.

## 3. Arxitekturaviy Komponentlar va Manba Maqomi (Level 1 — Level 3)
RAG tizimlari [Embeddings](/learn/embeddings) (yuqori o'lchamli semantik vektorlar), skalyar ko'paytma (dot product similarity) va [Transformers](/learn/transformers) generatorlariga tayanadi:

Embedding va Yaqinlik Qidiruvi: Matn bo'laklari va so'rovlar [Embeddings](/learn/embeddings) fazosiga o'tkazilib, ular orasidagi o'xshashlik [Vector](/learn/vector) skalyar ko'paytmasi yoki cosine similarity orqali hisoblanadi.
Sequence Transduction / Generation: Topilgan kontekst [Transformers](/learn/transformers) asosidagi auto-regressive modelga uzatiladi.

## 4. Python Amaliy Misoli: Vektor Yaqinligi bilan Retrieval

```python
import math

docs = {
    "chunk_1": ("Transformer self-attention barcha tokenlarni parallel bog'laydi.", [0.9, 0.2, 0.1]),
    "chunk_2": ("RAG tashqi hujjatlardan dalil topib, gallyutsinatsiyani kamaytiradi.", [0.2, 0.9, 0.4]),
    "chunk_3": ("Batch Normalization mini-batch o'rtacha va dispersiyasini normallashtiradi.", [0.1, 0.1, 0.95]),
}

def cosine_sim(a: list[float], b: list[float]) -> float:
    dot = sum(x * y for x, y in zip(a, b))
    na = math.sqrt(sum(x * x for x in a))
    nb = math.sqrt(sum(y * y for y in b))
    return dot / (na * nb)

query_vec = [0.18, 0.88, 0.35]  # "RAG nega kerak?" so'rovining embeddingi
ranked = sorted(
    ((cid, cosine_sim(query_vec, vec), text) for cid, (text, vec) in docs.items()),
    key=lambda x: x[1],
    reverse=True,
)
top_id, score, top_text = ranked[0]
print(f"Eng yaqin parcha: {top_id} (cosine={score:.3f}) -> {top_text}")
```
