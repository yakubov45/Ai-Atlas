## 1. Qisqacha ta'rif
Prompt Engineering — [LLM](/learn/llm) parametrlarini qayta o'qitmasdan, kirish matnini (prompt) strukturaviy shakllantirish orqali modelning diqqat (attention) mexanizmini va keyingi token bashoratini boshqarish usuli.

## 2. Nima uchun kerak?
[Transformers](/learn/transformers) ga asoslangan til modelining maqsadi matndagi keyingi so'zni bashorat qilishdir (3Blue1Brown, 2024). Modelning oxirgi pozitsiyadagi vektori oldingi barcha tokenlarning embeddinglaridan diqqat (attention) orqali ma'lumot yig'adi. Shu sababli kirish kontekstida berilgan ko'rsatmalar, misollar va mantiqiy mulohaza qadamlari (masalan, Yao et al., 2022 dagi ReAct: Synergizing Reasoning and Acting in Language Models) modelning chiqish ehtimolliklarini bevosita o'zgartiradi.

## 3. Qanday ishlaydi va Cheklovlari (Level 1 — Level 3)
Kontekstual Diqqat Yangilanishi (3Blue1Brown, 2024): Promptdagi har bir token Key va Value matritsalari orqali keyingi tokenlarning embeddinglarini boyitishda qatnashadi.
Reasoning va Acting Uyg'unligi: Yao et al. (2022, arXiv:2210.03629) til modellarida mantiqiy mulohaza yuritish (reasoning) va harakat qilishni (acting) birlashtirish yondashuvini taqdim etgan.
Arxitekturaviy Cheklovlar: Standart Self-Attention da hisoblash va xotira xarajatlari ketma-ketlik uzunligi bo'yicha kvadratik o'sadi (Vaswani et al., 2017), shu bois prompt uzunligini cheksiz oshirib bo'lmaydi.

## 4. Python Amaliy Misoli: Strukturaviy Prompt Builder

```python
def build_grounded_prompt(question: str, context_chunks: list[str]) -> str:
    joined_context = "\n".join(f"- [{i+1}] {c}" for i, c in enumerate(context_chunks))
    return (
        "Rol: Faqat berilgan manbalarga tayanib javob beruvchi AI muhandislik assistenti.\n"
        "Qoida: Agar javob kontekstda bo'lmasa, 'Manbada dalil yetarli emas' deb javob ber.\n\n"
        f"Kontekst:\n{joined_context}\n\n"
        f"Savol: {question}\n"
        "Javob:"
    )

print(build_grounded_prompt("ResNet nimani hal qildi?", ["Skip connection (y = F(x) + x) vanishing gradientni kamaytirdi."]))
```
