## 1. Qisqacha ta'rif
Tensor — skalyar (0D), [Vector](/learn/vector) (1D) va [Matrix](/learn/matrix) (2D) tushunchalarini ko'p o'lchamli massivlarga umumlashtiruvchi ma'lumotlar tuzilmasi bo'lib, PyTorch kabi kutubxonalarda mini-batchlar, tasvir feature map lari va multi-head attention proyeksiyalarini GPU da parallel hisoblash uchun xizmat qiladi.

## 2. Nima uchun kerak?
Chuqur o'rganish modellarida ma'lumotlar bir vaqtning o'zida bir nechta o'lcham bo'yicha guruhlanadi:

[CNN](/learn/cnn) va [Batch Normalization](/learn/batch-normalization): Mini-batchdagi m ta tasvirning C ta feature map i va H \times W fazoviy pozitsiyalari 4-tartibli tenzor (m, C, H, W) sifatida qayta ishlanadi (masalan, LeNet-5 C1 chiqishi m x 6 x 28 x 28).
[Transformers](/learn/transformers): Multi-Head Attention da h = 8 ta parallel bosh (har biri d_k = 64 o'lchamli) (batch_size, num_heads, seq_len, d_k) o'lchamli tenzor sifatida GPU da tezlashtiriladi.

## Python / PyTorch Amaliy Misoli

```python
import torch

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

Transformer batch: batch_size=2, seq_len=5, d_model=512
x = torch.randn(2, 5, 512, device=device)

8 ta parallel attention head (d_k = 64) ga ajratish:
(2, 5, 512) -> (2, 5, 8, 64) -> (2, 8, 5, 64)
x_heads = x.view(2, 5, 8, 64).transpose(1, 2) print("Device:", device) print("Multi-head tensor shape:", x_heads.shape) # torch.Size([2, 8, 5, 64])
```
