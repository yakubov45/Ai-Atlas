## 3. Qanday ishlaydi? Xotira Modeli, Dinamik Tiplash va To'plamlar

Dasturlashda ma'lumotlarni xatosiz boshqarish uchun Python xotirani qanday tashkil qilishini tushunish shart:

### 1. Ob'yektga Havola va Xotira Modeli (`is` vs `==`)
Python'da hamma narsa — sonlar, matnlar, to'plamlar ob'yektdir. O'zgaruvchi esa qiymatning o'zini emas, balki xotiradagi (Heap) ob'yekt manziliga ko'rsatib turuvchi havola hisoblanadi:

- `==` (Equality): Ikkita ob'yekt ichidagi qiymatlar tengligini tekshiradi.
- `is` (Identity): Ikkala o'zgaruvchi xotiradagi aynan bitta manzilga (`id()`) ko'rsatayotganini tekshiradi.
- **Aliasing xavfi:** Agar `b = a` deb yozilsa, yangi ro'yxat yaratilmaydi! Ikkala nom bitta xotiraga ulanadi. Natijada `b.append(99)` amali `a` ning ham qiymatini o'zgartirib yuboradi. Mustaqil yangi xotira ajratish uchun `.copy()` dan foydalaniladi.

```python
# 1. Teng qiymat, lekin turli xotira manzillari:
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)  # True  (qiymatlari teng)
print(a is b)  # False (xotirada ikkita alohida list)

# 2. Bitta ob'yektga ikki nom (Aliasing):
c = a
print(c is a)  # True  (aynan bitta xotira manzili)
c.append(4)
print(a)       # [1, 2, 3, 4] -> a ham o'zgardi!
```

### 2. Dinamik Tiplash va O'zgarmaslik (Mutability)
Python'da o'zgaruvchi e'lon qilinayotganda uning tipi oldindan yozilmaydi. Tip o'zgaruvchi ko'rsatayotgan ob'yektga bog'liqdir:

- **Skalyar primitivlar:** `int` (butun son), `float` (haqiqiy son), `str` (matn), `bool` (`True`/`False`). Bularning barchasi **o'zgarmas (immutable)** turlardir.
- **Dinamik massivlar:** `list` — o'zgaruvchan (mutable) bo'lib, xotiradagi manzilni o'zgartirmasdan yangi elementlar qo'shish (`.append()`) va o'chirish (`.pop()`) mumkin.
- **Kortejlar:** `tuple` — o'zgarmas (immutable) to'plam. Ma'lumotlarni tasodifiy o'zgarishlardan himoya qilish uchun ishlatiladi.
- **Lug'atlar:** `dict` — kalit-qiymat (Key-Value) juftligi. Kalit orqali qidirish hash-jadval asosida o'rtacha $O(1)$ vaqt oladi.
- **To'plamlar:** `set` — faqat unikal (takrorlanmas) elementlarni saqlovchi tartiblanmagan to'plam.

```python
# Har xil tiplarni o'zgaruvchiga yuklash:
x = 42                 # int
print(type(x))         # <class 'int'>

x = "Salom, Python!"   # str (til to'liq dinamik)
print(type(x))         # <class 'str'>
```

### 3. Shart Operatorlari (`if / elif / else`)
Dastur mantiqini boshqarish uchun shart bloklari ishlatiladi. Python'da qavslar o'rniga qat'iy **4 ta bo'shliq (indentation)** bilan bloklar ajratiladi:

```python
yosh = 20

if yosh >= 21:
    maqom = "Katta yoshli"
elif yosh >= 18:
    maqom = "Voyaga yetgan"
else:
    maqom = "O'smir"

print(f"Foydalanuvchi maqomi: {maqom}")
```

## 4. Amaliy Python Dasturlash Namunasi (Kod Tatbiqi)

Quyida xotiradagi nusxalash va to'plamlar bilan ishlashning amaliy namunasi keltirilgan:

```python
def xavfsiz_yangilash(asl_royxat: list[int], yangi_qiymat: int) -> list[int]:
    """
    Asl ro'yxatni o'zgartirmasdan, uning nusxasi ustida ishlovchi funksiya.
    """
    # 1. Alohida xotira ajratish (Shallow Copy)
    nusxa = asl_royxat.copy()
    
    # 2. Nusxaga yangi qiymat kiritish
    nusxa.append(yangi_qiymat)
    
    return nusxa

boshlangich = [10, 20, 30]
natija = xavfsiz_yangilash(boshlangich, 40)

print(f"Asl ro'yxat (o'zgarmadi): {boshlangich}")  # [10, 20, 30]
print(f"Yangi ro'yxat:            {natija}")       # [10, 20, 30, 40]
print(f"Ikkisi bitta xotiradami?  {boshlangich is natija}")  # False
```
