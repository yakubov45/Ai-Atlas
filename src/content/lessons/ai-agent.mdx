## 1. Qisqacha ta'rif
AI Agent — til modelida mantiqiy mulohaza yuritish (reasoning) va harakat qilishni (acting) uyg'unlashtirib (masalan, Yao et al., 2022 dagi ReAct yondashuvi), ko'p modulli yoki ko'p qadamli vazifalarni bajaruvchi tizim.

## 2. Nima uchun kerak?
Oddiy bitta chaqiruvli klassifikator yoki til modelidan farqli o'laroq, murakkab amaliy vazifalar (masalan, LeCun et al., 1998 tahlilidagi ko'p bosqichli hujjatlarni qayta ishlash konveyerlari yoki bilimga asoslangan NLP vazifalari) bir nechta qadam va modullarning o'zaro muvofiqlashgan ishlashini talab qiladi. Shunyu Yao va hammualliflar (2022, arXiv:2210.03629) til modellarida mulohaza yuritish va harakat qilishni birlashtiruvchi ReAct tizimini taklif etganlar.

## 3. Bilim va Xotira Qatlamlarining Farqlanishi (Level 1 — Level 3)
AI muhandisligida tizim foydalanadigan axborot manbalarini quyidagicha farqlash muhim:

Model-internal knowledge (Uzoq muddatli parametrik xotira): Hochreiter & Schmidhuber (1997) ta'riflaganidek, neyron tarmoqning sekin o'zgaruvchan vaznlarida (W) mujassamlashgan bilimlar.
Short-term activations / Conversation context (Qisqa muddatli kontekst): Joriy kirish hodisalari va ketma-ketlik tokenlarining aktivatsiyalarida ([RNN](/learn/rnn)/[LSTM](/learn/lstm) ichki holati yoki [Transformers](/learn/transformers) kontekst oynasida) saqlanuvchi tezkor ma'lumot.
External retrieval (Tashqi qidiruv): [RAG](/learn/rag) (Lewis et al., 2020) kabi bilimga asoslangan NLP vazifalarida tashqi manbalardan olinadigan ma'lumotlar.
Persistent application memory va Tools: Tashqi ilova xotirasi va vositalar ([Tools](/learn/tools)).

## 4. Python Amaliy Misoli: ReAct Tsikli (Thought -> Action -> Observation)

```python
def search_kb(query: str) -> str:
    kb = {
        "resnet": "ResNet (2015) y = F(x) + x skip connection kiritdi.",
        "rag": "RAG (2020) parametrli va tashqi qidiruv xotirasini birlashtiradi.",
    }
    return kb.get(query.lower(), "Manbada topilmadi.")

def react_step(question: str, max_steps: int = 2) -> list[str]:
    trace = [f"Savol: {question}"]
    # 1-qadam: Agent qaror qabul qiladi va vositani chaqiradi
    trace.append("Thought: ResNet haqidagi faktni bilim bazasidan tekshirish kerak.")
    obs = search_kb("resnet")
    trace.append(f"Action: search_kb('resnet') -> Observation: {obs}")
    # 2-qadam: Kuzatuv asosida yakuniy javob
    trace.append(f"Final Answer: {obs}")
    return trace[: max_steps * 2]

for line in react_step("ResNet nima yangilik kiritgan?"):
    print(line)
```
