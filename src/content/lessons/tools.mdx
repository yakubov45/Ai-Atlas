## 1. Qisqacha ta'rif
Tools (Vositalar) — [AI Agent](/learn/ai-agent) tizimlarida til modelining mantiqiy mulohaza yuritish (reasoning) qobiliyatini tashqi muhitda amaliy harakatlar (acting) bilan bog'lovchi tashqi funksiyalar va interfeyslar.

## 2. Nima uchun kerak?
Til modeli o'z holicha faqat keyingi token ehtimolligini hisoblaydi (3Blue1Brown, 2024). Tashqi tizimlar bilan ishlash uchun Yao et al. (2022, arXiv:2210.03629) tomonidan taklif etilgan ReAct: Synergizing Reasoning and Acting in Language Models paradigmasi mulohaza va harakatni birlashtiradi.

Izoh (Manba maqomi): Yao et al. (2022, arXiv:2210.03629) maqolasining bibliografik metama'lumoti tasdiqlangan; tool calling ijro xavfsizligi (sandboxing) esa tizim arxitekturasiga ko'ra alohida cheklovlar bilan boshqariladi.

## 3. Python Amaliy Misoli: ReAct Tool Schema va Xavfsiz Dispatch

```python
from typing import Callable

# 1. Ruxsat etilgan vositalar ro'yxati (Tool Registry / Whitelist)
def calculate_l2_norm(values: list[float]) -> float:
    return round(sum(v * v for v in values) ** 0.5, 4)

ALLOWED_TOOLS: dict[str, Callable] = {
    "calculate_l2_norm": calculate_l2_norm,
}

# 2. Model JSON chiqishini xavfsiz tekshirib bajarish
def execute_tool_call(name: str, args: dict) -> dict:
    if name not in ALLOWED_TOOLS:
        return {"error": f"Taqiqlangan yoki noma'lum vosita: {name}"}
    result = ALLOWED_TOOLS[name](**args)
    return {"tool": name, "observation": result}

print(execute_tool_call("calculate_l2_norm", {"values": [3.0, 4.0]}))
```
